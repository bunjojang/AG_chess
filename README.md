# AG Chess

변형 체스 규칙을 TFT 증강처럼 골라 붙이는 체스입니다. 시작할 때, 그리고 각자 6·12·18번째 턴을 마칠 때마다 증강 3장 중 1장을 고릅니다.

- **한 화면 2인**: 설정 없이 바로 됩니다.
- **온라인 2인**: 방을 만들고 링크를 보내면 상대가 남은 색 자리에 앉습니다. 계정 없이 익명으로 접속하고, 새로고침해도 같은 자리로 돌아옵니다. 세 번째로 들어온 사람은 관전합니다. 무르기와 무승부는 상대가 수락해야 합니다.

**플레이: https://bunjojang.github.io/AG_chess/** — 링크만 열면 됩니다. 설치나 가입은 필요 없어요.

## 운영 정보 (설정 완료)

플레이하는 사람은 아무것도 설정할 필요가 없습니다. 아래는 운영자용 기록입니다.

- **호스팅**: GitHub Pages, `main` 브랜치 루트
- **온라인 서버**: Firebase 프로젝트 `ag-chess-d97b8`
  - Realtime Database 위치: 싱가포르(asia-southeast1)
  - 익명 로그인 사용
  - 승인된 도메인에 `bunjojang.github.io` 추가
- **보안 규칙**: `database.rules.json`이 원본입니다. 이 파일을 고치면 Firebase 콘솔 → Realtime Database → 규칙에 다시 붙여 넣고 게시해야 반영됩니다.
- **무료 요금제 한도**: 동시 접속 100개(브라우저 탭 하나가 1개)라 동시에 약 50판까지 됩니다. 카드를 등록하지 않았으므로 한도를 넘으면 요금이 나가는 대신 접속이 막힙니다.
- **처음부터 다시 만들 때**(다른 계정으로 옮기거나 저장소를 복제한 경우): `docs/setup.md`의 순서를 따르세요.

### 보안 규칙이 막는 것
- 로그인(익명)하지 않은 접근
- 방에 앉은 두 사람이 아닌 사람의 쓰기. 관전자는 읽기만 합니다.
- 형식이 이상한 방 이름, 너무 큰 상태 데이터

### 알아 둘 한계
- **판정을 각자 브라우저에서 합니다.** 방에 앉은 사람이 개발자 도구로 상태를 조작하면 막을 수 없습니다. 친구끼리 두는 용도로 만들었고, 랭킹전을 하려면 서버 판정(Cloud Functions 등)이 필요합니다.
- 증강 후보 3장은 고르는 사람의 화면에서 뽑고 그 사람에게만 보여 줍니다. 다만 데이터 자체는 방 안에 있어서, 마음먹으면 상대 후보를 들여다볼 수 있습니다.
- 끝난 방은 자동으로 지워지지 않습니다. 무료 한도(저장 1GB)에 비하면 한 판이 수십 KB라 한참 쓸 수 있지만, 가끔 Realtime Database 데이터 탭에서 `rooms`를 지워 주면 됩니다.

## 로컬에서 고치고 시험하기

ES 모듈을 쓰기 때문에 파일을 더블클릭하면 안 되고, 간단한 서버로 열어야 합니다.

```bash
python3 -m http.server 8000
# http://localhost:8000              → 한 화면 모드
# http://localhost:8000/?net=mem     → Firebase 없이 온라인 흐름 시험 (같은 브라우저의 두 탭끼리)
```

`?net=mem`에서 방을 만들고 링크를 같은 브라우저의 다른 탭에 열면, Firebase 없이 두 사람 대전을 시험할 수 있습니다.

## 수정해서 올릴 때

GitHub Pages는 파일을 10분 정도 캐시합니다. 일부 파일만 새 버전으로 받으면 화면이 깨질 수 있어서, `index.html`과 `js/app.js`의 `?v=5` 숫자를 함께 올려 주세요(모두 같은 숫자로).

## 규칙

- **승리**: 체크메이트는 없습니다. 상대 킹을 잡으면 이깁니다(폭발로 날려도 같음). 킹을 공격받는 칸에 둬도 되지만, 상대가 잡으면 집니다. 화면에는 그런 칸을 빨간 점으로 표시합니다.
- **둘 수가 없을 때**: 둘 수 있는 수가 하나도 없으면 그 쪽이 집니다.
- **특수 승리**: 증강에 따라 언덕의 왕, 왕의 행진, 3회 공격, 사냥꾼 승리가 있습니다.
- **증강 고르는 시점**: 시작할 때, 그리고 각자 6·12·18번째 턴을 마친 직후 3장 중 1장을 고릅니다(총 4장).
- **라운드별 분류**

  | 분류 | 나오는 라운드 | 성격 |
  | --- | --- | --- |
  | 오프닝 | 1 | 고르는 즉시 시작 배치를 바꾼다 |
  | 미들 | 2·3 | 판을 흔드는 능력과 즉시 효과 |
  | 엔드 | 3·4 | 승급, 특수 승리 |
  | 기물 | 전부 | 기물 이동 강화, 보호막 |
  | 규칙 | 전부 | 승리 조건 추가 |

- **등급**: 라운드마다 실버/골드/프리즘 중 하나가 정해지고 양쪽이 같은 등급을 받습니다. 후보 3장은 각자 따로 뽑습니다. 그 등급에 맞는 후보가 모자라면 가까운 등급으로 채웁니다.
- **소급 없음**: 증강은 받은 순간부터 효과가 납니다. 3회 공격과 사냥꾼은 그때부터 세고, 드롭은 그 뒤에 잡은 말만 손패에 들어갑니다.
- **보호막**: 한 번 잡히거나 폭발에 휘말리는 걸 막고 사라집니다. 이때 공격한 기물은 제자리에 남습니다.
- **빙결**: 빙결된 기물은 정해진 턴 동안 움직이지 못하고, 상대 킹을 공격하지도 못합니다.
- **원자 포격과 드롭**: 직접 잡힌 말만 드롭 손패에 들어갑니다. 주변에서 휘말린 말은 그냥 사라지고, 승급한 말은 폰으로 돌아옵니다. 내 킹이 휘말리는 포획은 둘 수 없습니다.
- **고르는 순서**: 증강은 자기 턴이 끝난 직후 고릅니다. 시작 라운드는 백이 먼저 고르고, 흑은 그걸 보고 고릅니다.

증강 39종의 전체 설명은 게임 화면의 "증강 전체 목록"에 있습니다.
